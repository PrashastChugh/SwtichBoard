Rules

Rules answer matching requests instantly, before they reach this queue. Deny rules win over allow rules. Wildcard allow rules never match commands that chain or redirect (;, &&, |, >), so npm test* can't approve npm test && rm -rf ~.

Compact this session?

Compacting replaces the conversation so far with a summary. It frees space and makes every later step cheaper, but small details (exact error messages, file contents Claude read) can be lost. Best at a natural break: after finishing one task and before starting the next. Avoid it in the middle of debugging.
